# BIOS5801 Introduction — R 統計計算學習網站

給完全初學者的課堂學習本，對應蔡明軒老師 *BIOS5801: Introduction*（64 頁）。

## 開啟

```bash
open "/Users/mason/Desktop/BIOS5801_Intro_Study/index.html"
```

或：

```bash
cd "/Users/mason/Desktop/BIOS5801_Intro_Study"
python3 -m http.server 8766
```

然後瀏覽 http://127.0.0.1:8766/

## 建議用法

1. 先裝 R 與 RStudio（網站第 00 節）。
2. 左邊目錄往下讀，每一段紅色指令都複製到 Console 跑一次。
3. 最後做 12 題自我檢測。
