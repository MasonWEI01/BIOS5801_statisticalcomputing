06 · 投影片 8–10比較運算子與邏輯運算子

比較運算子也是二元：左邊一個物件、右邊一個物件，吐回 Boolean。

比較
6 > 5
6 < 5
6 >= 7
6 <= 5
6 == 5
6 != 5
## [1] TRUE ## [1] FALSE ## [1] FALSE ## [1] FALSE ## [1] FALSE ## [1] TRUE
> 大於、< 小於、>= 大於等於、<= 小於等於。
== 「是不是相等？」——兩個等號。
!= 「是不是不相等？」。
課堂警告：== 才是比較，= 不是！= 用來指定變數（跟 <- 類似）。若你寫 6 = 5，R 會報錯，因為你不能「指定」一個數字常數。

邏輯：& 且、| 或

把兩個 TRUE/FALSE 接起來。且：兩邊都真才真。或：有一邊真就真。

邏輯組合
(5 > 7) & (6 * 7 == 42)
(5 > 7) | (6 * 7 == 42)
(5 > 7) | (6 * 7 == 42) & (0 != 0)
(5 > 7) | (6 * 7 == 42) & (0 != 0) | (9 - 8 >= 0)
## [1] FALSE ## [1] TRUE ## [1] FALSE ## [1] TRUE
先算括號。5 > 7 是 FALSE；6*7==42 是 TRUE。
FALSE 且 TRUE → FALSE。
FALSE 或 TRUE → TRUE。
第三行：& 比 | 先算，所以是 FALSE 或 (TRUE 且 FALSE) = FALSE 或 FALSE = FALSE。
第四行最右邊又或上 TRUE，整句變 TRUE。
課堂註：雙寫的 && 與 || 不一樣，之後才教。現在請只用單個 &、| 做向量元素的且／或。

11 · 投影片 24–27向量運算、回收、比較

算術運算子對向量是「逐個位置算」，叫做 component-wise。

一樣長的兩個向量
x = c(7, 8, 10, 45)
y = c(-7, -8, -10, -45)
x + y
x * y
## [1] 0 0 0 0 ## [1] -49 -64 -100 -2025
7+(−7)=0，8+(−8)=0… 乘法同理：7×(−7)=−49。

Recycling 回收：短的會重複使用

短向量對齊長向量
x = c(7, 8, 10, 45)
x + c(-7, -8)
x ^ c(1, 0, -1, 0.5)
2 * x
## [1] 0 0 3 37 ## [1] 7.000000 1.000000 0.100000 6.708204 ## [1] 14 16 20 90
c(-7,-8) 只有 2 格，R 會當成 −7, −8, −7, −8 再相加：7−7=0，8−8=0，10−7=3，45−8=37。
次方：71=7，80=1，10−1=0.1，√45≈6.71。
單個數字是長度 1 的向量，所以 2 * x 等於每個元素乘 2。

逐元素比較

得到一串 TRUE/FALSE
x = c(7, 8, 10, 45)
x > 9
(x > 9) & (x < 20)
(x > 9) | (x < 20)
## [1] FALSE FALSE TRUE TRUE ## [1] FALSE FALSE TRUE FALSE ## [1] TRUE TRUE TRUE TRUE
7 與 8 都不大於 9；10 與 45 大於 9。第二行還要求小於 20，所以只剩 10。第三行「或」幾乎全真，因為每個數要嘛 >9，要嘛 <20。

整條向量相不相等：identical() 與 all.equal()

不要只看 x == y 的那串 TRUE
x = c(7, 8, 10, 45)
y = -c(7, 8, 10, 45)
x == -y
identical(x, -y)
identical(c(0.5-0.3, 0.3-0.1), c(0.3-0.1, 0.5-0.3))
all.equal(c(0.5-0.3, 0.3-0.1), c(0.3-0.1, 0.5-0.3))
## [1] TRUE TRUE TRUE TRUE ## [1] TRUE ## [1] FALSE ## [1] TRUE
-c(7,8,10,45) 對每個元素變號。x == -y 仍是長度 4 的邏輯向量。
identical() 問「整個物件是否完全同一」。
小數相減會有位元誤差，所以 identical 可能 FALSE，all.equal 允許微小誤差所以 TRUE。

Index 的日常意思是「按門牌去找」。對 vector、matrix、data frame、list 都適用同一套三種門牌：

  1. explicit integer indices：寫第幾個；負整數表示「去掉第幾個」。
  2. Boolean vector：一排 TRUE/FALSE，TRUE 留下、FALSE 丟掉。常常當場用比較做出來，課堂叫 on-the-fly。

E5 · Iteration 投影片 14–17流程控制：if / else / else if

Control flow 工具通常接受一個 condition 當輸入，再依這個條件的布林值決定下一步。與索引不同：if() 要的是一個 TRUE 或 FALSE，不是一排面具。

寫法角色
if()、else if()、else標準條件句：檢查一個是非，再決定跑哪一塊
ifelse()條件函數，而且可以向量化
switch()在好幾個選項裡挑一個

if() 與 else

日常語言：如果條件成立，做甲；否則做乙。else 可以省略——沒有「否則」時，條件不成立就什麼都不做。單行動作可以省略花括號 { }。

if (條件) { TRUE 時跑的程式 } else { FALSE 時跑的程式 }

非負就留下 x，否則留下 -x（絕對值）
x = 0.5
if (x >= 0) {
  x
} else {
  -x
}
if (x >= 0) x else -x
[1] 0.5 [1] 0.5
if 是關鍵字，不是函數名，但後面仍要括號。括號裡必須算出單一 TRUE 或 FALSE。>= 是「大於或等於」。
花括號包住「這一支路要跑的多行程式」，稱為 block。
Console 裡，R 發現這句還沒寫完，會把提示符暫時改成 +。那個 + 不是加法，是 continuation prompt。你不必自己打 +。
整個 if 表達式的值，等於被選中那一支的最後一個值。

}

條件 temp < 0 為 TRUE，走第一支，回傳 -temp，也就是 3。這又是一次絕對值。

else if()：一條以上的岔路

else if() 可以接在 if() 後面任意多次。R 由上往下問：第一個條件是 TRUE 嗎？是就做完離開；不是，才問下一個。最後的 else 仍然可有可無。

三岔路
x = -2

  x^2
} else if (x >= 1) {
  2*x-1
} else {
  -2*x+1
}
[1] 5
x^2 是 (-2)^2 = 4，4 < 4 為 FALSE，第一支不走。
接著 x >= 1？−2 不 ≥ 1，第二支不走。
於是走 else：-2 * x + 1 = -2 * (-2) + 1 = 5。
^ 是次方，比乘法更先算。Each else if() only gets considered if the conditions above it were not TRUE.

E6 · Iteration 投影片 18–20ifelse() 與 switch()

ifelse() 是一個函數（注意有括號、有引數），固定三個位置：① 條件；② 條件成立時的回傳值；③ 條件不成立時的回傳值。

三個引數的快速決定
x = -2
ifelse(x > 0, "x>0", "x<=0")
x = 2
ifelse(x > 0, "x>0", "x<=0")
x = -2
ifelse(x > 0, x, -x) # take absolute value
[1] "x<=0" [1] "x>0" [1] 2
第一個引數是條件，第二個是 TRUE 時給的東西，第三個是 FALSE 時給的東西。最後一行用它做絕對值。

它真正的威力在向量化：條件可以是一排 TRUE/FALSE，R 對每個位置各做一次選擇。課堂稱之為 elementwise comparison and operation。

對整條向量逐格選擇
x.vec <- 1:6
x.vec
x.vec^2
ifelse(x.vec^2 > 1, 2*x.vec-1, x.vec^2)
[1] 1 2 3 4 5 6 [1] 1 4 9 16 25 36 [1] 1 3 5 7 9 11
對 1：1^2 > 1 為 FALSE，留下平方 1。對 2：4 > 1 為 TRUE，改用 2*2-1 = 3。後面依此得到奇數 1, 3, 5, 7, 9, 11。
若改寫成 if (x.vec^2 > 1) ... 會失敗：if() 拒絕長度大於 1 的條件。
要決定「整段程式走甲或走乙」（例如要不要畫圖），用 if / else。要對一排數字各做一次選擇（及格標記、取絕對值），用 ifelse()。

條件是 w > 0，得到 FALSE, FALSE, TRUE。第三個位置換 "pos"，前兩個換 "not pos"。

導論已見 &（且）與 |（或）：它們是 elementwise 的。這一講用它來做「同時滿足兩個不等式」的篩選。

[1] -0.5498976 -0.3152276 0.5637759 0.6864934 0.5494977 -0.2256140 [7] -0.7284699 0.8007152 0.1329053 -0.9145317 [1] FALSE TRUE FALSE FALSE FALSE TRUE FALSE FALSE TRUE FALSE [1] -0.3152276 -0.2256140 0.1329053
先跑 set.seed(33); rnorm(6)，亂數種子才會對上課堂的 u.vec。
runif(10, -1, 1)：從 uniform 抽出 10 個數，下限 −1、上限 1。
-0.5 <= u.vec & u.vec <= 0.5：同時問「≥ −0.5」且「≤ 0.5」。& 兩側各是一條長度 10 的邏輯向量，逐位置做 AND。
方括號裡是布林面具，不是「去掉第 0.5 個」。負號黏在 0.5 上，表示負的零點五。

另外一對運算子是 && 與 ||。它們只回傳一個布林值，而且是 lazy 的：一旦左邊已經能決定答案，右邊根本不算。

左邊已能決定，右邊即使會報錯也不算
(0 > 0) && all(matrix(0,2,2) == matrix(0,3,3))
(0 > 0) && (ThisVariableIsNotDefined == 0)
(1 > 0) || (ThisVariableIsNotDefined == 0)
[1] FALSE [1] FALSE [1] TRUE
0 > 0 是 FALSE。對 AND 來說，左邊已是 FALSE，整個答案必是 FALSE，於是右邊不執行。
matrix(0,2,2) == matrix(0,3,3) 其實會因維度不合而報錯；ThisVariableIsNotDefined 也不存在。但因為懶惰，R 根本沒走到它們。
第三行同理：1 > 0 已是 TRUE，OR 不必看右邊。
若把第一行左右對調，右邊會先算，立刻報錯。課堂問 what if we switch the order，答案就是：懶惰保不住你了。
課堂口訣：Flow control requires one Boolean value and skip unnecessary operations。Rule of thumb：索引或 subsetting 用 & 與 |；if() 這類條件句用 && 與 ||。

while() 的意思是：「只要條件還是 TRUE，就把本體再跑一次。」它不管你走了幾步，只問「還要繼續嗎？」

做到對數還不超過 2 為止

  log.vec = c(log.vec, log(i))
  i = i+1
}
log.vec
[1] 0.0000000 0.6931472 1.0986123 1.3862944 1.6094379 1.7917595 1.9459101
i = 1：計數器要自己先有一個起始值。不像 for 會自動從向量頭走到尾。
log.vec = c()：從一條空向量開始，邊跑邊加長。

c(log.vec, log(i))：把新算出的對數接到舊向量後面。
i = i + 1：務必自己把計數器往前推。忘記這一行，條件永遠成立，就變成 infinite loop。那時按 Console 的 Stop，或快捷鍵 Esc。
這裡沒有預先配置 10 格。條件在 i = 8 時不進本體，所以沒有「空著的 0」。
for() versus while()。 for() 較適合「重複次數事先就清楚」；while() 較適合「走到那裡才認得出該停」。while() 更一般：每一個 for 都能改寫成 while，反之不然。例如 for (i in 1:n) log.vec[i] = log(i) 等價於 i = 1; while (i <= n) { log.vec[i] = log(i); i = i + 1 }。

while(TRUE) 與 repeat

while (TRUE) 與 repeat 做同一件事：把本體無限重複，直到裡面有東西把流程打斷（通常是 break）。

先做，再問要不要停
i = 1
log.vec = c()
repeat {
  log.vec = c(log.vec, log(i))
  i = i+1
  if (log(i) > 2) break
}
log.vec
[1] 0.0000000 0.6931472 1.0986123 1.3862944 1.6094379 1.7917595 1.9459101
結構相反：while 是「先問再做」；repeat 是「先做，再問要不要停」。所以 break 寫在本體末尾，問的是「下一輪的 i 還合不合格」。
結果剛好與課堂的 while 相同，因為 log(8) > 2 時 i 已經加到 8，但 8 的對數還沒被接進去。
一定要有逃生口。repeat 或 while (TRUE) 裡如果漏了 break（或條件永遠不成立），程式會一直跑。這不是 R 壞掉，是你沒給它停的理由。

E10 · Iteration 投影片 33–37少寫迴圈：向量化

課堂警告：有些人會過度使用 for() 與 while()。它們不是永遠必要。Remember vectorization should be used whenever possible（能向量化就向量化）。

同一個加法，兩種寫法

在 C、C++、Fortran 這類語言裡，兩條向量相加通常要自己寫迴圈。R 把這件事做成內建運算。

迴圈加法 vs a + b
a <- 1:5
b <- 4:8
vec_sum <- vector(mode = "numeric", length = length(a))
for (i in 1:length(vec_sum)) { vec_sum[i] <- a[i] + b[i] }
vec_sum
a + b
[1] 5 7 9 11 13 [1] 5 7 9 11 13
length(a)：向量有幾個元素。這裡是 5。
1:length(vec_sum)：造出 1 到 5，當計數器的軌道。這是「我要走遍每一格」的典型寫法。
a + b：R 對兩條等長向量逐位置相加。Python、MATLAB 也有類似的向量化。兩種寫法答案相同，但第二種才是 R 的習慣。

Clarity 清楚

語法直接說「我們在做什麼」（把 a 與 b 相加），而不是「我們怎麼一格一格做」。

Concision 簡潔

字比較少，出錯的縫也比較少。

Speed 速度

在 R 裡反覆改一條很長的向量很慢；向量化會把工作交給底層已優化的程式（通常是 C）。

本講總結（Iteration 投影片 37）

  1. 向量、矩陣、data frame、list 都有三種索引：整數、布林、名稱。
  2. 現算現用的布林索引非常有用。典型寫法：x[x > 0]。
  3. 具名索引對 data frame 特別重要。欄名比位置穩。
  4. List 的索引要小心 [ ] 與 [[ ]]。單括號留下子 list；雙括號拿出裡面的物件。多格不要用雙括號。
  5. if()、else if()、else 是標準條件句。條件必須是單一 TRUE/FALSE。
  6. ifelse() 是 if / else 的捷徑，而且能向量化。
  7. switch() 是一長串 if / else if / else 的捷徑，適合依字串標籤挑做法。
  8. for()、while()、repeat 是標準迴圈。break 用來提早停。for 適合已知軌道，while 適合已知停的條件。
  9. 不要過度使用顯式 for。向量化是朋友。apply() 與 **ply() 稍後會見。
給零基礎的第二張小抄：① 取出東西只有整數／布林／名稱三條路；② list 多格用 [ ]、拿出內容用 [[ ]] 或 $；③ if 管「整段走哪條」，ifelse 管「每個元素選哪個」；④ 索引用 & |，條件句用 && ||；⑤ 對整條向量做同一件事，先試向量化，再考慮寫迴圈。
